# Agentic Agile-V contributions

## Central principle

> Conversation is useful for discovering intent; structured artifacts are
> required for implementation; evidence is required for acceptance.

## Contributions

1. A synthesis of evidence from agentic coding research, GitHub adoption
   studies, repository-configuration work, productivity studies,
   issue-resolution benchmarks, and hardware verification benchmarks.
2. A conversation-to-contract model that separates exploratory dialogue from
   structured execution.
3. The Agentic Agile-V process model, combining Agile-V lifecycle structure
   with the SCOPE-V task loop.
4. Practical workflows and risk-adaptive evidence gates for feature work, bug
   fixing, test generation, firmware, and hardware or RTL development.
