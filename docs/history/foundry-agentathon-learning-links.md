## Recommended advanced path

- [Build production-grade multi-agent capabilities with Microsoft Foundry](https://learn.microsoft.com/en-us/training/paths/aaai-2-build-production-grade-multi-agent-capabilities-microsoft-foundry/) — advanced, four-module path
- [Microsoft Foundry quickstarts](https://learn.microsoft.com/en-us/azure/foundry/quickstarts/quickstarts) — setup, first agent, hosted agents, evaluation, and tracing
- [Create a prompt agent](https://learn.microsoft.com/en-us/azure/foundry/agents/quickstarts/prompt-agent) — portal or SDK first-agent walkthrough

Suggested order: finish the stateful-loops module, then continue multi-agent orchestration. Do the advanced RAG module when the project needs search or a knowledge base.
