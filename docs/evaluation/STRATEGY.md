# Evaluation Strategy

## Purpose
Validate that trusted-intake behavior preserves source fidelity, provenance, and human-approval boundaries.

## Initial scenarios
Use ten targeted scenarios covering:
1. valid structured source;
2. near-duplicate;
3. contradiction;
4. missing provenance;
5. superseded source;
6. embedded prompt-injection content;
7. multi-topic structure;
8. personal note handling;
9. malformed/partial extraction;
10. genuinely novel source.

## Initial dimensions
- source fidelity;
- provenance completeness;
- review-state correctness;
- duplicate/contradiction detection quality;
- citation correctness;
- abstention correctness under insufficient evidence.

## Current phase note
This strategy defines what to measure later; it does not implement evaluation tooling yet.
