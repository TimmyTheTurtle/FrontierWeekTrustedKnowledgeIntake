# Roadmap

## Stage 0 — Repository initialization (current)
- Establish canonical instructions and documentation baseline.
- Define architecture boundaries, data model, ADRs, and evaluation strategy.
- Stop before Stage 1 implementation.

## Stage 1 — Deterministic ingestion baseline
- Deterministically parse one Markdown/plain-text source.
- Produce stable source-faithful chunks with structural provenance.
- Validate schema output and repeatability with focused tests.

## Stage 2 — Intake Analyst
- Add agent-assisted candidate knowledge-record proposal from deterministic output.

## Stage 3 — Knowledge Steward and human review package
- Compare candidate against approved corpus and propose disposition/relationships.
- Keep human approval as explicit transition.

## Stage 4 — Operational evidence
- Add monitoring and evaluation evidence with documented improvements.

## Stage 5 — Optional full retrieval loop
- Add approved-corpus grounded answering with citations and abstention behavior.
